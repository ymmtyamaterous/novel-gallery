# 全体概要仕様書

## プロジェクト名

**Nobel Laureate Archive（ノーベル賞受賞者アーカイブ）**

ノーベル賞受賞者を調べられる Web アプリケーション。受賞理由・受賞年・部門・受賞者の経歴（略歴、国籍、生没年など）を閲覧できる学術的なギャラリーサイト。

---

## 目的・ゴール

- ノーベル賞受賞者の情報を体系的に閲覧・検索できるプラットフォームを提供する
- 研究者・学生・歴史愛好家などを対象にした、権威ある学術的なデザインで情報を提供する
- 受賞部門・受賞年・国籍などの軸で情報を探索しやすくする

---

## 対象ユーザー

| ユーザー種別 | 説明 |
|-------------|------|
| 一般訪問者 | 受賞者情報の閲覧・検索（ゲスト） |
| 登録ユーザー | お気に入り登録・個人コレクション管理 |

---

## 機能一覧

### コア機能

| 機能 | 優先度 | 説明 |
|------|--------|------|
| 受賞者一覧表示 | 必須 | ギャラリー形式で受賞者カード一覧を表示 |
| 受賞者詳細表示 | 必須 | 受賞者の略歴・受賞歴・経歴タイムラインを表示 |
| 部門別フィルタ | 必須 | 物理学・化学・医学生理学・文学・平和・経済学で絞り込み |
| 受賞年フィルタ | 必須 | 1901年〜現在の年で絞り込み |
| テキスト検索 | 必須 | 受賞者名・国籍・受賞理由のキーワード検索 |
| 賞一覧表示 | 必須 | 年別・部門別の受賞一覧 |

### ユーザー機能

| 機能 | 優先度 | 説明 |
|------|--------|------|
| ユーザー登録 | 必須 | メール + パスワードによる新規登録 |
| ログイン / ログアウト | 必須 | セッション管理 |
| お気に入り登録 | 推奨 | 受賞者・賞をブックマーク |
| お気に入り一覧 | 推奨 | マイページでブックマーク一覧を確認 |

---

## 技術スタック

| 区分 | 技術 |
|------|------|
| ランタイム | Bun |
| フロントエンド | TypeScript + React + TanStack Router + oRPC クライアント |
| バックエンド | Hono + oRPC |
| データベース | SQLite + Drizzle ORM |
| 認証 | Better-auth（メール + パスワード） |
| モノレポ管理 | Turborepo |
| コードフォーマット | Biome |
| Git フック | Lefthook |

## システム構成

```
┌──────────────────────────────────┐
│        Browser (Web Client)       │
│  TanStack Router + React + oRPC  │
└──────────────┬───────────────────┘
               │ HTTP / oRPC
               ▼
┌──────────────────────────────────┐
│         Hono Server              │
│  - Better-auth (/api/auth/*)     │
│  - oRPC Handler (/rpc)           │
│  - Static File Serving           │
└──────────────┬───────────────────┘
               │ Drizzle ORM
               ▼
┌──────────────────────────────────┐
│         SQLite Database          │
│  - auth 系テーブル               │
│  - laureates（受賞者）           │
│  - prizes（賞）                  │
│  - laureate_prizes（中間）       │
│  - favorites（お気に入り）       │
└──────────────────────────────────┘
```

---

## 主要フロー

### 受賞者閲覧フロー（ゲスト）

```
ホーム → 受賞者一覧（検索・フィルタ）→ 受賞者詳細
```

### ユーザー登録・ログインフロー

```
ホーム → ログインページ → 登録フォーム → ダッシュボード（マイページ）
```

### お気に入り登録フロー

```
受賞者詳細 → お気に入りボタン（要ログイン）→ マイページで一覧確認
```

## ディレクトリ構成（主要）

```
better-t-app/
  apps/
    web/          # フロントエンド（React + TanStack Router）
    server/       # バックエンド（Hono）
  packages/
    api/          # oRPC ルーター定義
    auth/         # Better-auth 設定
    db/           # Drizzle スキーマ・マイグレーション
    env/          # 環境変数バリデーション
    ui/           # 共通 UI コンポーネント
    config/       # 共通 TypeScript 設定
```

## 非機能要件

| 項目 | 要件 |
|------|------|
| セキュリティ | HTTPS 必須・httpOnly クッキー・CORS 制限 |
| レスポンシブ | モバイル（min 375px）〜デスクトップ（max 1280px）に対応 |
| アクセシビリティ | WCAG 2.1 AA 準拠を目標 |
| パフォーマンス | 初期ロード LCP 2.5 秒以内を目標 |
| データ初期投入 | サーバー起動時に DB マイグレーション＋シードを自動実行 |
