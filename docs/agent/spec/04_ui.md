# UI / 画面設計書

## デザインシステム概要

`docs/user/DESIGN.md` で定義された **"Digital Curated Gallery"** コンセプトに基づき実装する。

### カラーパレット（主要）

| トークン | 値 | 用途 |
|---------|-----|------|
| `primary` | `#000000`（Deep Navy） | グローバルナビ・主見出し・重要構造要素 |
| `secondary` | `#7a580f`（Noble Gold） | アクセント・インタラクティブ状態・受賞年 |
| `surface` | `#faf9f7`（Ivory） | 主背景（ページ全体） |
| `on-surface` | `#1a1c1b` | 本文テキスト |
| `on-surface-variant` | `#44474d` | サブテキスト・メタデータ |
| `outline` | `#75777e` | ボーダー |

### タイポグラフィ

| スタイル | フォント | サイズ | 用途 |
|---------|---------|--------|------|
| `display-lg` | Libre Caslon Text | 64px / 72px | ヒーロー大見出し |
| `display-lg-mobile` | Libre Caslon Text | 40px / 48px | ヒーロー大見出し（モバイル） |
| `headline-lg` | Libre Caslon Text | 32px / 40px | セクション見出し |
| `headline-md` | Libre Caslon Text | 24px / 32px | カード名前・ページタイトル |
| `body-lg` | Inter | 18px / 28px | 略歴・長文本文 |
| `body-md` | Inter | 16px / 24px | 一般本文 |
| `label-caps` | Inter | 12px / 16px, letter-spacing: 0.1em | 部門ラベル・メタデータチップ |

### コンポーネントルール

- **角丸**: `0.25rem`（4px）基本。ピル型ボタン禁止
- **シャドウ**: 使用しない。深度は背景色の差（トーナルレイヤー）で表現
- **ボーダー**: `1px solid #outline`（`#75777e`）
- **ホバー**: 2px 上方向の微移動 + Gold の薄いグロー
- **ボタン Primary**: Deep Navy 地 / Ivory テキスト
- **ボタン Secondary**: 透明 / 1px Navy or Gold ボーダー
- **メタデータチップ**: 角丸なし・`label-caps`

## 共通コンポーネント

### グローバルヘッダー

- **左**: サイトロゴ（"Nobel Laureate Archive" テキストロゴ、Libre Caslon Text）
- **中央**: ナビゲーションリンク（Laureates / Prizes）
- **右**: 検索アイコン + ログイン or ユーザーメニュー
- **スクロール挙動**: 背景を `surface-container-low`（`#f4f3f1`）に変え、1px ボトムボーダーを表示

### グローバルフッター

- サイト名・著作権表示
- ナビゲーションリンク（Laureates / Prizes / About）
- Nobel Prize 公式サイトへのリンク

### 検索バー（`RefinedSearch`）

- 中央配置・幅広め（最大 640px）
- Serif フォントのプレースホルダーテキスト: "Search laureates, fields, or motivations…"
- 虫眼鏡アイコン左配置
- フォーカス時: Gold 色 `outline`（1px）

### ギャラリーカード（`GalleryCard`）

- 上部: 受賞者肖像写真（矩形、アスペクト比 3:4）
- `label-caps` で部門名（例: "PHYSICS"）
- `headline-md` で氏名
- `body-md` で受賞理由の冒頭テキスト（最大 2 行、省略）
- 受賞年テキスト（Gold カラー、`label-caps`）
- 1px ボーダー
- ホバー: 2px リフト + Gold グロー

### メタデータチップ

- 角丸なし
- `surface-container-high`（`#e9e8e6`）背景
- `label-caps` テキスト
- 例: `PHYSICS`、`1969`、`United States`

### SCR-02 受賞者一覧 ギャラリー（`/laureates`）

#### レイアウト構成

```
┌───────────────────────────────────────────┐
│ グローバルヘッダー                         │
├───────────────────────────────────────────┤
│ フィルターバー                             │
│  [部門] [年] [国籍] [検索ボックス]        │
├───────────────────────────────────────────┤
│ 結果ヘッダー: "1,072 Laureates" 件数表示  │
├───────────────────────────────────────────┤
│ ギャラリーグリッド（12列 → 4カード/行）   │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐    │
│  │ Card │ │ Card │ │ Card │ │ Card │    │
│  └──────┘ └──────┘ └──────┘ └──────┘    │
│  …（繰り返し）                            │
├───────────────────────────────────────────┤
│ ページネーション                           │
└───────────────────────────────────────────┘
```

#### フィルターバー仕様

- 部門: ドロップダウン（All / Physics / Chemistry / …）
- 年: ドロップダウン（All / 2024 / 2023 / … / 1901）
- 国籍: テキスト入力（オートコンプリート）
- 検索: テキスト入力
- 選択中フィルターはメタデータチップ形式で表示し、×ボタンで個別解除可能

#### グリッド列数

| ブレークポイント | 列数 |
|----------------|------|
| モバイル (< 768px) | 1 列 |
| タブレット (768px〜) | 2 列 |
| デスクトップ (1024px〜) | 3〜4 列 |

### SCR-06 検索結果（`/search`）

- クエリパラメータ `?q=...` でキーワードを受け取る

### SCR-07 ログイン / 新規登録（`/login`）

#### レイアウト構成

```
┌───────────────────────────────────────────┐
│ グローバルヘッダー（簡易版）               │
├───────────────────────────────────────────┤
│ 中央カード                                │
│  - サイトロゴ                             │
│  - タブ: [Sign In] [Create Account]       │
│  - フォーム                               │
└───────────────────────────────────────────┘
```

#### Sign In フォーム

| 項目 | 説明 |
|------|------|
| Email | テキスト入力 |
| Password | パスワード入力（表示切り替えアイコン付き） |
| Submit | Primary ボタン "Sign In" |
| リンク | "Don't have an account? Create one" |

#### Create Account フォーム

| 項目 | 説明 |
|------|------|
| Name | テキスト入力 |
| Email | テキスト入力 |
| Password | パスワード入力（表示切り替えアイコン付き） |
| Confirm Password | パスワード確認入力（表示切り替えアイコン付き）。入力値が Password と一致するかバリデーション |
| Submit | Primary ボタン "Create Account" |
| リンク | "Already have an account? Sign In" |

#### バリデーション

- Email: メール形式チェック
- Password: 8 文字以上
- Confirm Password: Password と一致確認
- エラーはフィールド下にインラインで赤色テキスト表示

## レスポンシブ対応方針

| ブレークポイント | 変更内容 |
|----------------|--------|
| `< 768px`（モバイル） | ヘッダーナビをハンバーガーメニューへ・グリッド 1 列・マージン 20px |
| `768px〜`（タブレット） | グリッド 2 列・タイムライン縦配置 |
| `1024px〜`（デスクトップ） | グリッド 3〜4 列・タイムライン横配置可 |
| `max 1280px` | コンテンツ最大幅を 1280px に制限、両サイド余白 64px |

| 対象 | 挙動 |

| お気に入りボタン | ★ フィルアニメーション（Gold 色でフィル） |
